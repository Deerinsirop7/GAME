# Pixel Pet: Уютный домик

Пиксельный 2D-тамагочи на **Godot 4.3+** (GDScript). Выбери питомца (собака, кот,
попугай или рыбка) и его окрас, заботься о нём прямо мышкой: гладь, насыпай корм в миску,
мой губкой, играй. Копи монеты и обустраивай дом — от палатки до уютного дома с камином.
Смена дня и ночи по часам компьютера, погода, тихая музыка с паузами и звуки природы.
Никаких жёстких наказаний: питомец не болеет и не убегает.

## Как получить готовый .exe (ничего не устанавливая)

Сборку делает GitHub на своих серверах — файл `.github/workflows/build.yml`.

1. Зарегистрируйся на https://github.com и создай новый репозиторий (**New repository**,
   можно Private, без README).
2. На странице пустого репозитория нажми **uploading an existing file** и перетащи
   **содержимое** папки `pixel_pet` (не саму папку — `project.godot` должен лежать в корне).
   Перетаскивай из проводника все файлы и папки вместе, включая `.github`.
   Если папка `.github` не загрузилась (скрытые папки иногда не перетаскиваются):
   **Add file → Create new file**, в имени напиши `.github/workflows/build.yml`
   и вставь содержимое этого файла.
3. Нажми **Commit changes**. Откроется вкладка **Actions** — там запустится
   «Build Windows EXE» (3–5 минут).
4. Когда появится зелёная галочка, открой запуск → внизу **Artifacts** → **PixelPet-Windows**.
   Скачается zip с одним файлом `PixelPet.exe` — это готовая игра, её можно
   запускать и отдавать друзьям.

Если сборка красная — открой шаг «Smoke test» или скачай артефакт `build-logs`
и пришли строки с ошибками.

Пересобрать вручную: **Actions → Build Windows EXE → Run workflow**.

## Запуск в редакторе Godot (для разработки, по желанию)

Открой `project.godot` в Godot 4.3+ и нажми F5.

Сохранения лежат в `%APPDATA%\Godot\app_userdata\Pixel Pet_ Уютный домик\`
(`save.json` и `settings.json`).

## Управление

Курсор — твоя рука. Инструмент выбирается кнопками внизу или цифрами:

| Клавиша | Инструмент / действие |
|---|---|
| 1 — Гладить | зажми кнопку мыши и води по питомцу |
| 2 — Корм | кликни по миске (рыбке — по аквариуму); питомец сам подойдёт и поест |
| 3 — Мыть | три питомца губкой, отпусти — он отряхнётся (рыбке — протри стекло) |
| 4 — Игрушка | собака: брось мячик · кот: води пёрышком у земли · попугай: потряси колокольчиком · рыбка: води пальцем по стеклу |
| 5 | уложить спать / разбудить |
| B / H / M / Esc | магазин / дом или двор / музыка / меню |
| F11 | полный экран |

Клавиши работают на любой раскладке. Отладка (только из редактора): F2 погода, F3 +1 час, F4 +100 монет.

## Механики

- **Нужды**: сытость, радость, энергия, чистота. Падают медленно (0,4–0,7 в минуту),
  у каждого питомца свои множители. Во сне радость не падает, энергия быстро растёт.
- **Монеты**: +1 каждые ~15 секунд, пока питомец сыт и доволен (сытость > 50,
  среднее настроение ≥ 70), и +2 за действие, когда оно действительно нужно.
- **Пока игра закрыта** (до 8 часов) нужды падают, но не ниже 20, а довольный
  питомец копит немного монет.
- **Дружба** растёт за полезную заботу и немного ускоряет доход.
- **Уют** = сумма уюта предметов + уровень дома: замедляет падение радости и ускоряет доход.
- **Жильё**: Палатка → Шалаш (150) → Маленький дом (600) → Уютный дом (1500, камин). В дом можно зайти с самого начала, интерьер растёт вместе с жильём.
- **Предметы**: 5 для двора и 9 для комнаты; у лежанки, кровати и ящика игрушек есть особые бонусы.
- **Время суток** берётся с часов компьютера; в настройках есть «быстрое время»
  (1 игровой час = 1 минута). **Погода**: солнце, облака, дождь (меняется раз в 7–15 минут).

## Структура

```
project.godot            настройки проекта (640x360, масштаб x2, пиксельная фильтрация)
scenes/main.tscn         единственная сцена; экраны создаются из кода
scripts/autoload/        Catalog (данные), Art (текстуры), GameState (логика и сохранения),
                         TimeWeather (время и погода), Audio (музыка и звуки)
scripts/ui/              ui_kit (тема и виджеты, автозагрузка UIKit), need_bar, shop, settings_panel
scripts/world/           world_scene (мир и свет), sky, weather_fx, pet_view (поведение питомца)
scripts/screens/         title, pet_select, home
assets/sprites, audio    сгенерированные ассеты
tools/                   генераторы ассетов на Python
```

## Как менять арт, звук и баланс

Весь арт и звук генерируются скриптами (нужны Python 3, Pillow и numpy):

```
python tools/gen_sprites.py
python tools/gen_audio.py
```

Папку `assets` в репозиторий загружать не нужно — сборка на GitHub создаёт её сама.

- Цены, описания и позиции предметов, дома, параметры питомцев — `scripts/autoload/catalog.gd`.
- Скорость нужд, монет, сна и оффлайн-прогресс — константы в начале `scripts/autoload/game_state.gd`.
- Цвета неба по часам — `KEYS` в `scripts/world/sky.gd`.
